# RSS Customizer

Take control of your WordPress feed — the part of your site scrapers read
first.

## Features

- **Feed delay** — hold new posts out of the feed for N minutes, so you can fix
  typos before scrapers grab the post.
- **Feed footer** — append copyright/attribution text to every feed item, so
  scraped copies still point back to you.
- **Category exclusion** — keep chosen categories out of the feed entirely.
- **Item count** — override the default feed length without touching
  Settings → Reading.
- **Comment feed toggle** — disable comment feeds (they 404) if you don't
  need them.

All changes apply to feeds only; the site itself is untouched.

## Installation

1. Upload the plugin folder to `wp-content/plugins/`.
2. Activate it.
3. Configure under Settings → RSS Customizer.
